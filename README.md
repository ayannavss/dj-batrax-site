# DJ Batrax — site otimizado

Site estático em HTML, CSS e JavaScript puro, preparado para GitHub e Vercel.

## Layout premium preservado

Esta versão mantém integralmente o layout premium aprovado: mesma composição, cores, foto, tipografia, seções, espaçamentos, animações, CTAs e comportamento responsivo. As alterações são exclusivamente técnicas — performance, SEO, acessibilidade, segurança e preparação para publicação.

## URL pública

Produção: https://dj-batrax-site.vercel.app/

Canonical, Open Graph, Twitter Card, JSON-LD, robots e sitemap usam a URL pública definitiva.

## Publicação

O repositório está conectado à Vercel. Novos commits na branch `main` geram deploy automático em produção.

## Arquivos principais

- `index.html`: página completa e responsiva
- `assets/images/dj-batrax-hero.webp`: imagem crítica do hero
- `assets/images/dj-batrax-hero-640.webp` e `dj-batrax-hero-960.webp`: versões responsivas
- `assets/images/og-image.webp`: compartilhamento social em 1200 × 630 px
- `assets/fonts/`: fontes locais em WOFF2
- `assets/icons/` e `favicon.ico`: favicons
- `robots.txt` e `sitemap.xml`: rastreamento e indexação
- `vercel.json`: cache e cabeçalhos de segurança
